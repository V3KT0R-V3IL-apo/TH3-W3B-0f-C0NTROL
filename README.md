# TH3 B0DY

A structural map of how power operates in the world.

Not who is evil. How the system works — regardless of individual intent.

---

## What this is

TH3 B0DY maps the institutions, mechanisms, and systems that control the five fundamental layers of human life: food, health, knowledge, work, and money. It connects those control structures to the financial infrastructure that funds them, the state apparatus that protects them, the intelligence agencies that enforce them, and the deeper layers of consciousness and language through which they operate on human experience.

It is not a conspiracy map. Conspiracy maps connect dots without evidence standards. TH3 B0DY has evidence standards built into its architecture — every claim is labelled by the quality of evidence behind it, and every node contains a genuine counterpoint because the counterpoints are true.

It is not an ideology. Ideologies present one framing as the only possible framing. TH3 B0DY documents the structure of the world as it is, acknowledges what is uncertain, and is explicit about where it is making inferences rather than citing evidence.

It is a map. Maps are not the territory. This one knows it is a map.

## Evidence levels

Every claim in TH3 B0DY is labelled with one of four evidence levels. Read these before you read the claims.

**[Documented]** — Court records, official investigations, declassified government documents, financial disclosures, peer-reviewed research, parliamentary reports, or journalism with named sources and documentary evidence. Something a researcher could verify independently from primary sources.

**[Credible allegation]** — Reported by serious journalists or researchers. Evidence exists and is credible. Not proven in court or through official process.

**[Contested]** — Genuinely debated among historians, researchers, or investigators. Evidence exists on both sides. TH3 B0DY does not resolve the contest — it documents it.

**[Theoretical]** — Logical inference from known structures and documented patterns. No direct evidence. No source citation. These are structural arguments, not factual claims. They are included because they are worth thinking about, not because they are established fact.

The distinction between these levels is the difference between a map and propaganda. Take it seriously.

## Counterpoints

Every node in TH3 B0DY contains a `[Counterpoint]` block. These are not token gestures toward balance. They are genuine. The counterpoints are included because they are true — because the world is complex enough that the same institution can be simultaneously documented as causing harm and documented as producing genuine benefit.

If you find a counterpoint unconvincing, that is a signal to investigate further — not a signal that the counterpoint is wrong.

## Source citations

All documented claims are cited in `TH3_B0DY_SOURCES_v0.8.json`, published alongside this file.

Each citation contains: title, author, publisher, year, URL, and a one-line note on what the source confirms.

**URL rot policy:** URLs are provided as access points, not as primary identifiers. If a URL is dead, use the title + author + publisher + year to locate the source independently. DOI links (`doi.org` prefix) are permanent by design. Non-DOI links are locatable via metadata.

Inline hyperlinks on `[Documented]` labels within the map open source documents directly. 250 inline links across 36 nodes as of v0.7.

## Verification

The SHA-256 hash displayed in the bottom left of the map verifies the file has not been modified since publication.

To verify manually:

1. Open the file in a text editor
2. Find the `<span id="canonical-hash">` element
3. Copy the 64-character hash value
4. Replace that value in the file with the text `HASH_PENDING`
5. Compute the SHA-256 of the modified file
6. Compare with the canonical hash published in this repository

A match confirms the file is unmodified. A mismatch means the file has been altered.

## Contributing

TH3 B0DY is an evolving document. It is wrong about some things. It is incomplete about many things.

If you have:
- A documented source that contradicts a claim in the map
- A documented source that strengthens or extends a claim
- Evidence of a connection between nodes that is not currently mapped
- A counterpoint stronger than the one currently included

Open an issue or submit a pull request. Every contribution will be evaluated against the evidence standards above. Contributions that meet the standard will be incorporated with attribution in the next version.

What will not be accepted: claims without documented sources, conspiracy theories that do not meet the [Documented] or [Credible allegation] standard, and arguments that remove counterpoints without replacing them with stronger ones.
